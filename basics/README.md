# Shell Scripts for Basics Project / Scripts Shell pour le Projet de Base

This directory contains simple shell scripts as part of the Holberton School curriculum. / Ce répertoire contient des scripts shell simples dans le cadre du cursus Holberton School.

## Scripts / Scripts

**0-current_working_directory**  
**Description:** Prints the absolute path of the current working directory / Description : Affiche le chemin absolu du répertoire de travail actuel.

**1-listit**
Description: Lists files and directories in the current directory.

**2-bring_me_home**
Description: Changes the current directory to the home directory.

**3-listfiles**
Description: Lists all files including hidden ones.

**4-listmorefiles**
Description: Displays details of files in a long listing format.

**5-listfilesdigitonly**
Description: Lists files whose names contain only digits.

**6-firstdirectory**
Description: Creates a directory named First Directory.

**7-movethatfile**
Description: Moves a file to another location.

**8-firstdelete**
Description: Deletes a specified file.

**9-firstdirdeletion**
Description: Deletes a specified directory.

**10-back**
Description: Changes to the previous directory.

**11-lists**
Description: Custom listing of directory contents.

**12-file type**
Description: Displays the type of a given file.

**13-symbolic_link**
Description: Creates symbolic links to files or directories.

**14-copy_html**
Description: Copies an HTML file to a target directory.

**15-lets_move**
Description: Moves multiple files or directories.

**16-clean_emacs**
Description: Removes unwanted Emacs backup files.

**17-tree**
Description: Recursively lists directories in a tree-like format.
