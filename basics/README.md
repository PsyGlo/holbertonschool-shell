# Shell Scripts for Basics Project / Scripts Shell pour le Projet de Base

This directory contains simple shell scripts as part of the Holberton School curriculum. / Ce répertoire contient des scripts shell simples dans le cadre du cursus Holberton School.

## Scripts / Scripts

**0-current_working_directory**  
**Description:** Prints the absolute path of the current working directory / Affiche le chemin absolu du répertoire de travail actuel.

**1-listit**
Description: Lists files and directories in the current directory / Liste les fichiers et répertoires dans le répertoire courant.

**2-bring_me_home**
Description: Changes the current directory to the home directory / Change le répertoire courant pour le répertoire personnel.

**3-listfiles**
Description: Lists all files including hidden ones / Liste tous les fichiers, y compris les fichiers cachés

**4-listmorefiles**
Description: Displays details of files in a long listing format / Affiche les détails des fichiers dans un format de liste longue

**5-listfilesdigitonly**
Description: Lists files whose names contain only digits / Liste les fichiers dont les noms ne contiennent que des chiffres

**6-firstdirectory**
Description: Creates a directory named First Directory / Crée un répertoire nommé

**7-movethatfile**
Description: Moves a file to another location / Déplace un fichier vers un autre emplacement

**8-firstdelete**
Description: Deletes a specified file / Supprime un fichier spécifié.

**9-firstdirdeletion**
Description: Deletes a specified directory / Supprime un répertoire spécifié

**10-back**
Description: Changes to the previous directory / Revient au répertoire précédent

**11-lists**
Description: Custom listing of directory contents / Liste personnalisée du contenu d’un répertoire

**12-file type**
Description: Displays the type of a given file / Affiche le type d’un fichier donné

**13-symbolic_link**
Description: Creates symbolic links to files or directories / Crée des liens symboliques vers des fichiers ou des répertoires

**14-copy_html**
Description: Copies an HTML file to a target directory / Copie un fichier HTML vers un répertoire cible.

**15-lets_move**
Description: Moves multiple files or directories / Déplace plusieurs fichiers ou répertoires

**16-clean_emacs**
Description: Removes unwanted Emacs backup files / Supprime les fichiers de sauvegarde Emacs indésirables

**17-tree**
Description: Recursively lists directories in a tree-like format / Liste récursivement les répertoires dans un format en arbre
