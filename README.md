# Holberton School - Shell Projects / Projets Shell  
Welcome to my shell scripting projects repository as part of my initial exploration through Holberton School pre-inscription.  
Bienvenue dans mon dépôt de projets d'écriture de scripts shell, réalisé dans le cadre de ma pré-inscription à Holberton School. 

--- 

## About This Repository / À propos de ce dépôt  
This repository contains exercises and small projects focused on fundamentals of Bash scripting and Linux shell environment management.  
Ce dépôt contient des exercices et petits projets axés sur les fondamentaux du scripting Bash et la gestion de l'environnement shell Linux. 

### Covered Topics / Thèmes abordés 
- Basic shell commands and scripting principles / Commandes shell de base et principes du scripting
- Initialization files, environment variables, and expansions / Fichiers d'initialisation, variables d'environnement et expansions
- Input/output redirections and filters / Redirections d'entrée/sortie et filtres
- File permissions and ownership management / Permissions de fichiers et gestion des propriétaires

### Repository Structure / Structure du dépôt

### Learning Objectives / Objectifs pédagogiques  
- Develop practical skills in writing and chaining shell commands / Développer des compétences pratiques dans l’écriture et l’enchaînement de commandes shell
- Understand the role and customization of shell environment / Comprendre le rôle et la personnalisation de l’environnement shell
- Practice managing files and permissions through scripting / S’exercer à la gestion des fichiers et des permissions par le biais de scripts
- Get familiarized with input/output manipulation in Linux / Se familiariser avec la manipulation des entrées/sorties sous Linux
