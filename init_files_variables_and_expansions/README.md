# Shell Init Files, Variables, and Expansions / Scripts d’initialisation Shell, variables et expansions﻿  

- **This directory contains exercises and scripts designed to teach essential shell scripting concepts focused on shell initialization files, environment and local variables, and various shell expansions. This helps to master shell environment customization, efficient scripting, and command line productivity.** 

*Ce répertoire contient des exercices et scripts conçus pour enseigner les concepts essentiels du scripting shell, avec un focus sur les fichiers d’initialisation du shell, les variables d’environnement et locales, ainsi que diverses expansions. Cela permet de maîtriser la personnalisation de l’environnement shell, le scripting efficace et la productivité en ligne de commande.*  

- **Through these exercises, I learnt how to configure the shell environment with init files, manipulate variables with proper scoping, and use expansions for dynamic command execution and string manipulation. I attained proficiency in automating tasks, managing shell sessions, and writing flexible, powerful shell scripts.**  

*À travers ces exercices, j’ai appris à configurer l’environnement shell avec des fichiers d’initialisation, à manipuler les variables avec un champ d’application approprié, et à utiliser les expansions pour exécuter des commandes dynamiques et manipuler des chaînes. J’ai acquis une maîtrise dans l’automatisation de tâches, la gestion des sessions shell et l’écriture de scripts shell flexibles et puissants.*
