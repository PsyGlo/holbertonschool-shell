Shell Init Files, Variables, and Expansions
This directory contains exercises and scripts designed to teach essential shell scripting concepts focused on shell initialization files, environment and local variables, and various shell expansions. This helps to master shell environment customization, efficient scripting, and command line productivity.

Through these exercises, I learnt how to configure the shell environment with init files, manipulate variables with proper scoping, and use expansions for dynamic command execution and string manipulation. I attained proficiency in automating tasks, managing shell sessions, and writing flexible, powerful shell scripts.
