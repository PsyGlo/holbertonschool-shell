Shell Permissions

This directory contains scripts and exercises aimed at understanding and manipulating file and directory permissions in a Unix/Linux environment. The projects cover changing file ownership, setting permission modes, and managing execute, read, and write privileges for users, groups, and others.

This is fundamental for system security, efficient access control, and safe multi-user collaboration.

Scripts

- Each script focuses on a specific permission or ownership task, progressively building skills in Unix permission management.

- 0-iam_betty
Prints the effective username of the current user.

1-who_am_i
Displays detailed identity information of the current user.

2-groups
Lists all groups that the current user belongs to.

3-new_owner
Changes the ownership of a specified file to a new user.

4-empty
Creates an empty file or tests if a file is empty.

5-execute
Adds execute permissions to a specified file.

6-multiple_permissions
Sets multiple permissions (read, write, execute) on files or directories.

7-everybody
Grants read permission to all users on a file.

8-James_Bond
Applies specific ownership and permission settings, possibly named after a user test case.

9-John_Doe
Similar to the above, sets user/group ownership and permissions for a test user.

10-mirror_permissions
Mirrors permissions from one file or directory to another.

11-directory_permissions
Adjusts permissions specifically for directories.

12-directory_permissions
(Duplicate name is likely an oversight) Manages directory ownership and permissions.

13-change_group
Changes the group ownership of a file or directory.

14-change_owner_and_group
Changes both owner and group for a specified file or directory.

15-symbolic_link_permissions
Sets permissions related to symbolic links.

16-if_only
Script demonstrating conditional permission setting or checks.
